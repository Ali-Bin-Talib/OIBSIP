# Number Guessing Game (Java Development Task 2)

## Objective
A console-based game where the computer generates a random number between 1 and 100, and the user attempts to guess it within a limited number of attempts, receiving higher/lower hints[cite: 16, 17].

## Tech Stack
- Java[cite: 16]

## Features
- Random number generation[cite: 16, 17]
- Attempt counter and limit enforcement (7 max attempts)[cite: 16, 17]
- "Too High!" and "Too Low!" feedback hints
- Play again loop with score tracking[cite: 16, 17]
