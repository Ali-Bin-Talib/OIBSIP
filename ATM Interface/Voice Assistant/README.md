# Voice Assistant (Python Programming Task 1 - Beginner Tier)

## Objective
A Python-based voice assistant that listens to spoken commands through the microphone and responds with useful actions such as greetings, telling the time/date, and performing web searches[cite: 26].

## Tech Stack
- Python[cite: 26]
- `speech_recognition` (for microphone input)[cite: 26]
- `pyttsx3` (for text-to-speech output)[cite: 26]
- `webbrowser` & `datetime` (for system tasks)[cite: 26]

## Features
- Voice input capture via microphone[cite: 26]
- Interactive text-to-speech feedback[cite: 26]
- Real-time time and date retrieval[cite: 26]
- Web search automation[cite: 26]
- Graceful error handling for unrecognized speech[cite: 26]
