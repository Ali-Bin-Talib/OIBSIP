# Temperature Converter

A simple web tool that converts temperature between Celsius, Fahrenheit and Kelvin.

## Features
- Numeric input with validation (rejects empty or non-numeric values)
- Unit selector: Celsius, Fahrenheit, Kelvin
- Convert button showing all three units at once
- Absolute zero check with a friendly error message
- Clean, centred, responsive layout

## Tech Stack
HTML5, CSS3, JavaScript (Vanilla)

## How to Run
Open `index.html` in any browser.

## Formulas
- C to F: (C x 9/5) + 32
- F to C: (F - 32) x 5/9
- C to K: C + 273.15
