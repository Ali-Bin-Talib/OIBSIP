# FitLife Landing Page

A responsive landing page for a fictional fitness app.

## Features
- Sticky navigation bar with 4 links
- Hero section with headline, subheadline and call-to-action button
- Features, About and Testimonials sections
- Footer with contact and social links
- Consistent colour palette and responsive layout (Flexbox)

## Tech Stack
HTML5, CSS3

## How to Run
Open `index.html` in any browser.
