# BMI Calculator (Python Programming Task 2)

## Objective
A Python program that calculates a user's Body Mass Index (BMI) based on their weight and height inputs, and classifies their health category.

## Tech Stack
- Python (Core logic, conditional statements, and error handling)

## Features
- Dynamic calculation using formula: $\text{BMI} = \frac{\text{weight}}{\text{height}^2}$
- Standard health category classification (Underweight, Normal weight, Overweight, Obese)
- Input validation to handle non-numeric entries or zero/negative values
