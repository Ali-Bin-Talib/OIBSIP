# ATM Interface (Java Development Task 3)

## Objective
A console-based simulation of an ATM machine that allows users to authenticate with a PIN, view transaction history, withdraw, deposit, and transfer funds[cite: 17].

## Tech Stack
- Java (Object-Oriented Programming with multiple classes)[cite: 17]

## Features
- Secure PIN authentication with maximum 3 attempt limits[cite: 17]
- Main Menu with options for Transaction History, Withdraw, Deposit, Transfer, and Quit[cite: 17]
- Balance validation to prevent overdrafts / insufficient funds[cite: 17]
- Transaction logging stored via ArrayList[cite: 17]
