# To-Do App with Login (Android)

Track: Android App Development | Task 2 | OIBSIP

## Features
- Sign-up and Login with validation
- Passwords stored as salted SHA-256 hashes in SQLite (no plain text)
- Session handling and Logout
- User-specific tasks stored in SQLite
- Add task (name + notes), mark complete (strikethrough), delete
- Empty state message

## Tech Stack
Android Studio, Java, XML, SQLite

## How to Run
Open the project in Android Studio, sync Gradle, and run on an emulator or device.
